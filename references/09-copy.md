# 09 · 界面文案

**文案即设计。** 界面上每个字都是设计对象，不是填充物——它决定按钮宽度、行数、换行点、空态高度、以及用户敢不敢点下去。

判定原则与 `07-ai-tells.md` 一致：一个写法之所以是 tell，不是因为它本身错，而是因为它**与简报无关地、无差别地出现在任何产品上**。

---

## A. 按钮：动词 + 宾语

1. 结构固定为 `动词 + 宾语`，宾语必须是界面上真实存在的东西（一个对象、一份文件、一笔记录）。
2. 破坏性操作写出后果与范围，不写"是/否"。
3. 按钮动词与结果页动词一致：按钮写"创建项目"，成功后标题写"项目已创建"。
4. 长度 2–5 个汉字或 1–3 个英文词；超出说明这个动作要拆成两步。
5. 一屏只允许一个主按钮（由 `--accent` 承载），次级动作用描边或纯文字；不出现两个结果相似但动词不同的按钮。

| 禁用 | 为什么无信息 | 替换 |
|---|---|---|
| `Submit` | 提交什么？点了会发生什么 | `保存收货地址` |
| `OK` / `确定` | 必须读上下文才知道后果 | `删除这篇草稿` |
| `Cancel` | 只说了否，没说否到哪 | `继续编辑` / `放弃修改` |
| `Yes` / `No` | 指代不明，脱离按钮组即失效 | 用具体动作替换 |
| `Send` | 缺宾语 | `发送给 3 位评审人` |
| `Learn more` / `Get started` / `了解更多` | 空承诺、泛 | `查看定价明细` / `创建免费账号` |
| `Next` / `下一步` | 不知道下一步是什么 | `填写发票信息` |

| 破坏性场景 | 禁用 | 替换 |
|---|---|---|
| 删单条 | `确定` | `删除这条记录` |
| 批量删 | `确定删除` | `永久删除 12 个文件` |
| 退出未保存 | `离开` | `放弃修改并离开` |

## B. 错误信息公式

**发生了什么 + 为什么 + 怎么办。** 三段缺一段即是无效错误信息。

| 场景 | 坏 | 好 |
|---|---|---|
| 上传超限 / 字段校验 | `上传失败` / `输入无效` | `文件 24.6 MB，超过 10 MB 上限。压缩后再传，或拆成两个 ZIP。` / `手机号需要 11 位数字，当前 9 位。` |
| 登录 | `密码错误` | `邮箱或密码不匹配。检查大小写，或点此用邮件重设密码。` |
| 网络 | `Something went wrong` | `没连上服务器，改动已存在本地。检查网络后点“重新提交”。` |
| 权限 | `无权限` | `你当前是只读成员，无法编辑。联系管理员开通编辑权限。` |
| 服务端 | `Error 500` | `服务器处理超时，这笔订单没有扣款。30 秒后重试，或联系 support@yourdomain.com。` |

| 错误情形 | 信息位置 |
|---|---|
| 单字段错误 | 该字段**下方**，与字段视觉绑定，`aria-describedby` 关联 |
| 跨字段错误 | 涉及的第一个字段下方，说明涉及哪几个字段 |
| 整表错误（提交失败） | 主按钮**上方**；页顶汇总允许存在，但必须有就近提示，且汇总项可点击锚点 |

禁止只在页顶汇总而字段处无声；禁止只用红色边框（必须边框 + 图标 + 文字三重编码，见 `07-F`）。

## C. 空态与加载态

空态不是空白，是一条通向有数据状态的路径。结构：**说明现状 + 一个动作 +（可选）示例数据**。禁止单独一行 `暂无数据`，禁止放三张卡片，禁止用插画替代说明。

| 空态类型 | 结构 | 示例 |
|---|---|---|
| 首次使用 | 说明这里会出现什么 + 主动作 | `还没有项目。项目用来把同一个需求的稿件收在一处。` → `创建第一个项目` |
| 搜索无结果 | 复述查询 + 调整建议 | `没有匹配“折扣码批量导出”的文档。试试更短的关键词，或搜“导出”。` |
| 筛选为空 | 列出生效条件 + 一键清除 | `当前筛选：近 7 天 · 未结算 · 华东区。` → `清除全部筛选` |
| 错误 / 权限为空 | 原因 + 下一步 | `数据加载中断。` → `重试`；`你的角色是访客，看不到财务字段。` → `申请查看权限` |

| 加载场景 | 选择 | 判据 |
|---|---|---|
| < 100ms；100ms – 1s 且结构已知 | 不显示加载指示；原位占位且不改变布局 | 闪烁与位移都比等待更烦 |
| > 300ms，结构已知 | 骨架屏，**尺寸与最终内容一致** | 尺寸不符会直接造成 CLS |
| 结构未知、量大 | 进度条 + 已处理数量（`已导入 1,240 / 3,000 行`） | 用户需要判断要不要等 |
| 用户操作结果可预测 | 乐观更新：先呈现结果，失败回滚并说明 | 回滚时必须讲清原状态已恢复 |
| > 10s | 转后台 + 完成后通知 | 不许让用户盯屏 |

禁止全屏转圈遮罩（阻断用户）；禁止乐观更新无回滚；禁止骨架屏用与真实行数无关的固定条数。

## D. 表单：标签、占位符、帮助、错误

| 元素 | 职责 | 规则 |
|---|---|---|
| `label` | 说明这个字段**是什么** | 必须存在且可见，**禁止用 placeholder 替代 label** |
| `placeholder` | 只展示**格式示例** | 只放格式样例（`138 0013 8000`），不放字段名、不放说明句 |
| 帮助文本 | 说明约束与后果 | 常显于 label 下方，不要等出错才出现；写清不可逆后果 |
| 错误 | 说明哪里错、怎么改 | 见 B 定位规则；三重编码；`aria-describedby` 关联 |
| 必填标记 | 必填占多数时标**选填** | 用文字 `选填`，不用星号 |

| placeholder 反例 | 问题 | 正确做法 |
|---|---|---|
| `请输入姓名` / `请输入邮箱地址` | 字段名当占位，输入后消失，用户忘了这格填什么 | label `姓名` + placeholder `张明远`；label `邮箱` + placeholder `name@yourdomain.com` |

## E. 语气标定与禁用句式

同一动作（导出）在不同产品类型下的写法；禁止同一产品内混用"您/你"，禁止跨类型借语气（开发者工具写"温馨陪伴"）。

| 产品类型 | 语气 | 人称 | 示例 |
|---|---|---|---|
| 开发者工具 | 精确、零修辞、术语正确 | 你 · 命令式 | `导出 2,431 行 CSV` |
| 金融 / 合规 | 保守、可审计、说明后果 | 您 · 我们 | `导出近 90 天流水。文件含账户信息，请勿转发给第三方。` |
| B2B SaaS | 结论先行、可量化 | 你 | `导出本月用量报表` |
| 消费级应用 | 短、具体、轻 | 你 | `导出这段行程` |
| 医疗健康 | 中性、不承诺、给下一步 | 您 | `下载检查报告（PDF）。结果请由医生解读。` |
| 高定 / 奢侈 | 克制、少字、不自夸 | 您 | `预约到店` |

| 禁用句式 | 为什么是 tell | 替代 |
|---|---|---|
| `A · B · C` 中点 meta 行 | 模板语法，用标点伪装排版结构 | 逗号、分行，或用表格承载 |
| `WORD — fragment` 空格加间隔号 | 伪排版，把一句话切成没说完的两截 | 写完整句 |
| 全大写 + 大字距 eyebrow 标签 | 与内容无关的形式外壳（07-B2） | 正常大小写 + 字号色阶区分 |
| `Submit` / `OK` / `确定` | 无信息动词 | 见 A 的替换表 |
| `Something went wrong` / `Learn more` / `了解更多` | 无信息、空承诺 | 见 B 的公式；说出用户会知道什么 |
| 赋能 / 一站式 / 极致体验 / 无缝衔接 | 空心形容词，删掉不损失信息 | 写具体能力与数字 |
| `Feature 1` / `功能一` / `标签1` | 占位标签残留 | 写真实功能名 |
| `还没有账号？` / 首次使用？反问引导 | 表演式对话 | 直接写动作：`创建账号` |
| `Let's` / 让我们一起 / `Oops` / `哎呀` | 表演式亲和，把故障娱乐化 | 命令式 + B 的错误公式 |
| 感叹号连用、全句全大写 | 廉价强调，等于没有强调 | 一个感叹号都不留 |

## F. 中英混排与数字

| 情形 | 规则 | 示例 |
|---|---|---|
| 中文与英文 / 数字之间 | 加一个半角空格 | `导出 12 个 CSV 文件` |
| 中文与全角标点 | 不加空格 | `支持 Markdown，也支持纯文本。` |
| 数字与单位之间 | 加空格；`%`、`°` 不加 | `24 MB`、`128 GB`、`72%`、`25°` |
| 括号 | 中文语境用全角；括号内为纯英文时用半角 | `（含税）`、`(Beta)` |
| 专有名词大小写 | 按官方写法，禁止自作主张 | `GitHub`、`iOS`、`macOS`、`PostgreSQL`、`npm`、`OAuth` |
| 代码 / 命令 | 用 `code` 标记，内部标点保持半角 | `运行 pnpm build，然后看 dist/` |
| 标点与省略号 | 一句内不混用中英标点；中文用 `……` 与 `——`，禁用 `---`、`..` 及间隔号拼接 | `支持导出，也支持 API。`（不用 `支持导出, 也支持 API.`） |

| 数字类型 | 规则 | 示例 |
|---|---|---|
| 大数 | 中文界面用 万 / 亿；英文界面用 K / M / B | `12.4 万` / `12.4K` |
| 精度与对齐 | 同一列保留相同小数位；表格数字右对齐 + `tabular-nums` | 表格内全部一位小数 |
| 货币 | 符号 + 千分位 + 两位小数；跨币种必须写代码 | `¥1,280.00`、`US$89.00` |
| 时间 | 绝对 `2026-04-03`（禁止 `04/03`）；7 天内用相对，超出用绝对 | `3 小时前` → `4 月 3 日` |
| 区间与负数 | 单位只写一次用 `–`；负数减号 + 颜色 + 符号三重编码 | `10–20 MB`、`−¥240.00` |
| 变化率与量级 | 写明基准与方向；大文件保留一位小数 | `较上周 +18%`、`2.4 GB`（不写 `2.437 GB`） |

禁止 `$1,234.56` 当全站唯一数字（07-D）；数字必须与业务量级一致。

## G. 真实内容（否决 Jane Doe 效应）

| 禁止 | 替代 |
|---|---|
| `Lorem ipsum` / `Jane Doe` / `John Smith` | 该产品的真实文案（长度覆盖最短与最长两种情况）；多样化真实名字：`林知远`、`欧阳澈`、`陈屿`、`Nadia Rahimi` |
| `Acme Corp` / `user@example.com` | 行业贴合的可信公司名：`长川物流`、`Northline Freight`；用自己域名为后缀并标注样例：`name@yourdomain.com` |
| 通用头像占位 / 纯灰方块占位 | 首字母头像（色相由名字哈希决定）；带尺寸标注的**有结构**占位（主体色块 + 比例说明） |
| `01 / 02 / 03` 假编号 / `标签1` / `选项A` | 只在真实序列上使用编号；标签写真实名且长度不统一（模拟真实数据） |
| `$1,234.56` | 该商品的真实价格带：`¥128.00`、`¥1,280.00`、`¥12,800.00` |

**长度覆盖规则**：任何列表 / 表格 / 卡片，必须各准备一条**最短**与**最长**现实数据（如姓名 `李岩` 与 `欧阳澈·阿尔斯兰`，标题 4 字与 38 字），用来验证换行、截断、省略号行为。只测中等长度等于没测。
