# 01 · Design Read：需求推断与旋钮推导

P0 阶段的全部工作。目标：**在动手前把隐含判断变成可被推翻的显式判断。**

---

## A. 先读信号（Read the Room）

按以下顺序扫描，找到越多，Design Read 越准。

| 信号源 | 读什么 |
|---|---|
| 用户原话 | 名词（产品是什么）、动词（用户来干什么）、形容词（他自己描述的调性） |
| 已有资产 | 现有页面、品牌手册、logo 色、竞品链接、截图、设计稿 |
| 项目上下文 | 仓库名、`package.json`、已有的 CSS 变量与字体、既有组件风格 |
| 历史偏好 | 记忆中这个人之前选过什么、拒绝过什么 |
| 使用场景 | 设备（手机/桌面）、环境（办公室/户外/电视墙）、时长（3 秒扫过 / 长时间停留） |
| 业务约束 | 转化目标、法律合规文案、必须出现的元素（价格、免责声明） |

**优先序**：用户原话 > 已有资产 > 历史偏好 > 你的推断。任何情况下，**简报里的原话赢**，包括它点名要一个"陈词滥调"的风格。

---

## B. 输出契约（强制格式，一行）

在写任何代码之前输出：

```
Design Read: <主体> · <受众> · <核心用途> · <审美方向> · DIALS V<n> M<n> D<n>
```

**示例**

```
Design Read: 独立咖啡烘焙商的产品站 · 25–40 岁自购豆子的城市消费者 · 让人相信豆子新鲜并下单 ·
Editorial Broadsheet（用生豆产地作图片线索，用烘焙日期作排版主角）· DIALS V5 M3 D4
```

紧接着一行，写**为什么是它而不是默认值**：

```
反默认检查：默认会做成"暖奶油底 + 衬线大标题 + 陶土强调色"；改走冷白纸面 + 印刷红 + 多栏报纸结构，
原因是简报强调"日期与批次"，编号与规则线能真正编码这个信息。
```

## C. 旋钮推导表

| 场景 | V | M | D |
|---|---|---|---|
| 企业官网 / 信任型落地页 | 3–4 | 2–3 | 3–5 |
| 产品 SaaS 应用内界面 | 2–4 | 3–4 | 5–7 |
| 营销落地页（转化导向） | 6–8 | 5–7 | 3–4 |
| 作品集 / 个人站 | 7–10 | 6–8 | 2–4 |
| 数据仪表盘 / 监控台 | 2–3 | 2–3 | 8–10 |
| 电商商品页 | 4–6 | 3–4 | 6–8 |
| 内容媒体 / 长文 | 4–6 | 2–3 | 4–6 |
| 移动端消费应用 | 3–5 | 5–6 | 3–5 |
| 品牌发布 / 事件页 | 8–10 | 7–9 | 2–3 |

**旋钮如何驱动输出**

- `V` 高：允许破格网格、叠压、旋转、非标准滚动、非常规首屏。`V` 低：严格栅格、可预测、以下属关系取胜。
- `M` 高：滚动驱动、物理动画、连续反馈。`M` 低：只有状态反馈（hover / focus / 提交）与一次编排入场。
- `D` 高：紧凑行高、表格优先、信息可扫读、字号跨度小。`D` 低：大留白、字号跨度大、一屏一个信息。

**任一旋钮 ≥7 时，必须在设计提案里说明它服务于什么目标**，否则降一档。

---

## D. 歧义处理

- 用户只给了"做个网站"这类零信息简报：**不要问一堆问题**。自己定主体（含受众与用途），直接给提案，并说明这是假设。
- 简报自相矛盾（"极简但要抓眼球"）：判定为旋钮冲突，输出两组 token 对比（V2/M2 与 V8/M7），让用户选。
- 只允许问**一个问题**，且必须是无法靠推断解决的那个。剩下的全走提案。

---

## E. 主体先行（Ground in the subject matter）

审美差异不来自"风格库"，来自**主体世界的材料与行话**。

动手前回答三个问题：

1. 这个主体世界里，从业人员会盯着看的那样东西是什么？（烘焙师的曲线、分析师的数字、乐手的效果器板）
2. 这个世界的材料是什么？（纸、金属、荧光屏、帆布、混凝土）
3. 这个世界的行话怎么用？（不要把"通知设置"写成"webhook 配置"）

首屏的第一眼，应该是**上面第 1 条那样东西的最合适形态**——一个数字、一张图、一次交互、一段真实切片。而不是"大标题 + 副标题 + 两个按钮"。

> 默认处理就是：大数字 + 小标签 + 支撑统计 + 渐变强调。只有当它确实是这个主体的最佳表达时才用。

---

## F. 记忆与迭代

如果环境里有可写的笔记位置，记下每次尝试过的方向与被否掉的理由。人类设计师靠记忆避免重复，你也要有外部记忆。下次给同一个人做设计时，先读它。
