# 05 · 布局与架构

P2/P3 阶段使用。布局不是把容器摆整齐，是**信息层级在二维上的编码**。下面的每个数值都能直接落成 CSS。

---

## A. 栅格：版心与栏数

| 场景 | 版心 | 栏数 | 对齐 |
|---|---|---|---|
| 长文 / 单列阅读 | `max-width: 62ch`（45–80 字符） | 1 | 左 |
| 编辑排版（媒体、出版） | `min(1180px, 92vw)` | 6–12 可变栏 | 左 |
| 产品应用内界面 / 后台表单 | `100%` + 侧栏 `240–280px`；表单 `max-width: 720px` | 12 / 1–2 | 左 |
| 营销落地页 | `min(1200px, 92vw)` | 12，常用 5+7 / 4+8 非对称 | 混合 |
| 数据仪表盘 | 满宽，内边距 `16px` | 12 等宽，`gap: 8px` | 左 + 数字右对齐 |

```css
.page   { width: 100%; max-width: 1180px; margin-inline: auto;
          padding-inline: clamp(16px, 5vw, 40px); }
.grid   { display: grid; grid-template-columns: repeat(12, minmax(0, 1fr));
          gap: var(--sp-6); }
.span-7 { grid-column: span 7; }
```

`minmax(0, 1fr)` 不是可选项。`1fr` 的最小尺寸默认是 `auto`，内容一长就撑破轨道——横向滚动由此产生。flex 子项同理，需显式 `min-width: 0`。

**放弃栅格的三个条件**（满足任一即放弃）：元素要按内容尺寸呼吸（chip 集合、按钮组、标签云），用 `flex-wrap` + `gap`；布局本身就是排版手段（Brutalist 叠压、Maximalist 旋转），用绝对定位手排；内容是表格或时间线，用 `grid-template-columns: auto 1fr` 或原生 `<table>`，不要塞进 12 栏。

---

## B. 间距刻度：4pt 基准

| token / px | 用途 |
|---|---|
| `--sp-1` 4 · `--sp-2` 8 | 图标与文字间隙 · 控件内边距、密集行距 |
| `--sp-3` 12 · `--sp-4` 16 | 高密度卡内距 · 基础分隔、列表项内边距 |
| `--sp-5` 20 · `--sp-6` 24 | 段落间距 · 标准卡内距、栅格 gap |
| `--sp-8` 32 · `--sp-10` 40 | 低密度卡内距 · 子区块间距 |
| `--sp-12` 48 · `--sp-16` 64 | 区块间距（高密度）· 区块间距（标准） |
| `--sp-20` 80 · `--sp-24` 96 | 区块间距（低密度）· 章节间距（低密度） |
| `--sp-32` 128 | 首屏与页脚留白 |

只允许表内值加 `0` 与 `100%`。出现 `37px`、`13px` 即在制造节奏噪声（见 `07-ai-tells.md` C3）。

刻度不固定为 px，而是**由 `VISUAL_DENSITY` 缩放**：

```css
:root { --density: 1; }  /* D1–3 → 1.25 · D4–6 → 1 · D7–10 → 0.75 */
:root {
  --sp-2:  calc(8px  * var(--density));
  --sp-4:  calc(16px * var(--density));
  --sp-6:  calc(24px * var(--density));
  --sp-12: calc(48px * var(--density));
  --sp-16: calc(64px * var(--density));
}
```

UI 只允许引用 `--sp-*`。改旋钮只改 `--density` 一个值，全站节奏同步位移。

## C. `VISUAL_DENSITY` 三档映射

| 参数 | D1–3 舒展 | D4–6 平衡 | D7–10 密集 |
|---|---|---|---|
| 正文字号 / 行高 | `16px` / `1.7` | `15–16px` / `1.55` | `13–14px` / `1.35–1.4` |
| 标题行高 / 字阶比 | `1.1–1.15` / `1.333` | `1.15–1.25` / `1.25` | `1.2–1.25` / `1.2` |
| 章节 `padding-block` | `80–128px` | `48–80px` | `32–48px` |
| 卡片 `padding` | `32px` | `24px` | `12–16px` |
| 列表行高 | `56px` | `40px` | `28–32px` |
| 圆角 / 一屏信息量 | `--r-lg` 主导 / 一个 | 三级刻度 / 二到三个 | `--r-sm` 主导 / 表格优先 |
| 数字 | 常规字形 | 常规字形 | `font-variant-numeric: tabular-nums` |

D7 以上（Data-Dense Dashboard / Technical Terminal）额外两条硬规则：状态色必须配图标或文字，不靠颜色单独承载语义；数字列右对齐。阴影会让密集界面变脏，层级改用背景明度差与 1px 描边。

## D. 响应式：移动优先

**断点（`min-width` 递进，禁止 `max-width` 降级写法）**

| 断点 | 目标 |
|---|---|
| 基础（无媒体查询） | 375px 起的单列 |
| `480px` / `640px` | 大屏手机两列控件 / 小屏平板卡片两列 |
| `768px` | 平板：导航展开、非对称栅格启用 |
| `1024px` / `1280px` | 桌面侧栏常驻 / 宽桌面最大留白 |
| `1536px` | 超宽：版心锁死，不再拉伸 |

验收尺寸集合：`320 / 375 / 414 / 768 / 1024 / 1440`。320px 与 375px 必须零横向滚动——WCAG 1.4.10 Reflow 在 320 CSS px 起要求内容无需双向滚动即可阅读。

**375px 起零横向滚动的实现清单**

| 手段 | 写法 |
|---|---|
| 宽度单位 | `width: 100%`，不用 `100vw`（含滚动条宽度，必然溢出） |
| 长 token | `overflow-wrap: anywhere`，让 URL / 标识符 / 用户内容可断 |
| flex / grid 文本子项 | `min-width: 0`，否则不收缩 |
| 图片 / 表格 | `max-width: 100%; height: auto` / 外包 `overflow-x: auto` 或改卡片布局 |
| chip、标签集合 | `flex-wrap` 换行或 `+n` 折叠溢出项，不要 `overflow: hidden` 硬裁 |
| 绝对定位装饰 | `inset-inline-end` 约束 + 容器 `overflow-x: clip` |

**容器查询（`@container`）的使用时机**：只在组件被投放到**多个不同宽度的容器**时使用（同一张卡片既进 320px 侧栏又进 900px 主栏）。页面级布局仍用媒体查询——媒体查询看视口，容器查询看容器，判断的不是同一件事。

```css
.card-host { container-type: inline-size; container-name: media; }
.media { display: grid; grid-template-columns: 1fr; gap: var(--sp-4); }
@container media (min-width: 30rem) {
  .media { grid-template-columns: 200px 1fr; }
}
```

## E. 非对称布局（`DESIGN_VARIANCE` 驱动）

| V | 手法 | 具体做法 |
|---|---|---|
| 1–3 | 严格栅格 | 所有块起始于栏边界，`span` 取偶数，对齐策略全站统一 |
| 4–6 | 跨栏 + 偏移 | 标题跨 7 栏起于第 2 栏（`grid-column: 2 / span 7`）；图片溢出到版心外 `margin-inline: calc(-1 * var(--sp-8))`；留白按 `2:1` 而非 `1:1` 分配 |
| 7–10 | 破格 | 叠压（`z-index` + 负 `margin`）、旋转 `±1–4deg`、文本绕行、非标准滚动方向 |

非对称只有一条判据：**它有没有编码信息**。标题跨 7 栏而非 12 栏，是因为右侧要留侧栏注的位置；图片向左溢出，是因为它要与下方正文左边界形成对照。说不出为什么偏移就是随机——回 V4。

禁用 `text-align: center` 处理两行以上正文。`text-wrap: balance` 只给标题用（限制在 6 行内），正文用 `text-wrap: pretty` 消除孤字。

## F. 层叠与 z-index

```css
:root { --z-base: 0; --z-sticky: 10; --z-overlay: 20; --z-modal: 30; --z-toast: 40; }
```

**只允许使用表内值。** 需要新层时，取表中未占用的整数位（如抽屉 `--z-drawer: 15`），登记进此表再引用——任何地方都不允许出现字面量。

三个陷阱：`transform`、`filter`、`opacity < 1`、`will-change`、`isolation: isolate`、`contain: paint` 都会创建新栈上下文，父级层级低时子级写 `z-index: 9999` 也越不出去；`position: sticky/fixed` 自带栈上下文，粘性头一进入，内部所有层级基准都变；需要关舱时用 `isolation: isolate` 把组件层级锁在内部，而不是给内部元素疯狂堆数字。

---

## G. 滚动与 sticky

**粘性头只在一种情况下用**：某控件在长内容滚动期间必须保持可达（表格表头、筛选栏、段落导航、返回按钮）。装饰性粘性头不加。`position: sticky` 未设 `top/bottom` 等同 `relative`，必须给偏移值。

| 副作用 | 处置 |
|---|---|
| 粘性头遮住键盘焦点目标（违反 WCAG 2.4.11 Focus Not Obscured） | 滚动容器上设 `scroll-padding-top: var(--header-h)` |
| 锚点跳转后标题被压在头下 | 目标元素上设 `scroll-margin-top: var(--header-h)` |
| 祖先有 `overflow: hidden/auto/clip` 时 sticky 静默失效 | 逐级查祖先链，把 overflow 移到真正该滚动的容器 |
| grid 子项默认 `align-self: stretch` 使 sticky 无位移空间 | 显式 `align-self: start` |

`scroll-padding-*` 设在**滚动容器**上，`scroll-margin-*` 设在**被滚动到的目标**上：前者是容器内缩，后者是目标外扩；锚点跳转用后者更稳，因为它跟着元素走。

**滚动容器嵌套**默认避免。确实需要（如对话框内独立滚动区）时，给内层加 `overscroll-behavior: contain` 阻断滚动链，并确认该容器可聚焦（`tabindex="0"` + 区域 `role` 与可访问名称），否则键盘用户无法滚动它。`scroll-behavior: smooth` 必须包在 `@media (prefers-reduced-motion: no-preference)` 内。

## H. 布局的 AI 味重灾区

**病灶结构**：每个 section 都是「居中大标题 + 副标题 + 三张等宽卡」。它之所以是生成痕迹，不在于不好看，而在于这一结构**不携带任何来自简报的信息**——换成任何主题都成立。同页出现三次以上即判定为结构缺陷（见 `07-ai-tells.md` C1、A5）。硬约束：**同一页面至少两种容器形态**。

| 替代结构 | 何时用 | 骨架 |
|---|---|---|
| 非对称双栏 | 有主内容与旁注之分 | 主 `span 8` + 侧 `span 4`，侧栏起点低于主栏 |
| 跨栏标题 + 分栏正文 | 编辑排版、深度内容 | 标题 `span 7`，正文两段 `span 5` 并行 |
| 常驻索引 + 内容区 | 文档、规范、目录型页面 | 左 `240px` 粘性索引 + 右流式内容 |
| 表格主结构 | 数据密集 | 粘性表头 + 分组分隔线，取消卡片 |
| 编辑流 + 边注 | 长文 | 正文 `62ch` 单列，边注用负 margin 外挂 |
| 整幅色块分区 | 需要强节奏 | 一个 section 用满幅强调色，其余保持纸面 |

## I. 首屏

首屏第一眼必须是**该主体世界里从业者会盯着看的那样东西**（衔接 `01-design-read.md` E 节），而不是一个 CTA 外壳。

| 主体 | 首屏第一眼 |
|---|---|
| 咖啡烘焙商 | 烘焙日期 + 曲线，或当批生豆的产地与处理法 |
| 开发者工具 | 一段可读的真实输出（日志、请求、diff），不是「更快的构建」 |
| 监控台 / 数据产品 | 实时表格的前几行 + 当前状态，不是渐变大数字仪表 |
| 乐器、器材、硬件 | 产品的规格表与接口图 |
| 出版 / 媒体 | 本期头条的完整开场，或目录 |
| 建筑 / 工作室 | 一张能看清材料与光的图，配项目名称与年份 |
| 电商商品页 | 商品本身 + 价格 + 库存，第一屏即可决策 |

**禁止的默认首屏**：大标题 + 副标题 + 两个按钮；居中 hero + 三张卡；全屏渐变 + 玻璃拟态卡；渐变大数字 + 小标签 + 支撑统计。

首屏必须包含一个真实交互或一段真实数据切片——一个可操作控件、一个真实数字、一段真实文本。只有标题和一个「开始使用」的首屏，等于没有首屏。
